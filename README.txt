ANNUAL LAWN PLANNER FOR ANDROID

Upload every file in this folder to the root of the same GitHub repository. Do not place the files inside another folder in the repository.

Files required:
- index.html
- manifest.webmanifest
- lawn-icon-192.png
- lawn-icon-512.png

After GitHub Pages publishes the site, open the HTTPS address in Chrome on Android. Refresh the page, use the three-dot menu, then select Install app or Add to Home screen. Remove an older shortcut first so Android retrieves the updated version.
